# Work plan — 23 Aug 2026

Ordered so nothing built early has to be rebuilt later.

## 1. Albus the cactus (SwiftUI)
The mascot is used by Focus Mode, headers, empty states and onboarding, so it
comes first — everything after can lean on it. Flat geometry, reproducible from
`1 Prototype/mascot.jsx` with no image assets. Spike density encodes workload:
calm / busy / cooked.

## 2. Token refinement
The design's type scale is smaller and tighter than what shipped: overline 10 at
.14em tracking, detail 12.5, card title 16.5, display 30 with negative tracking.
Fixing this first means every screen after inherits it instead of being patched.

## 3. Home shows all upcoming work
Today only ever showed sessions placed today, so an evening plan looked empty.
Becomes: Today, Tomorrow, then grouped by date. Session card rebuilt to match
the design — inset colour rail, HAPPENING NOW badge, course/kind row, chevron.

## 4. Focus Mode, and session logging that cannot be faked
Currently a checkbox marks a session done instantly, which makes the estimator's
input worthless. Replace with a real session:

- Full-screen, dark, minimal; the cactus is the subject.
- Countdown driven by a **monotonic clock**, so changing the device clock does
  not complete a session.
- Survives backgrounding; a local notification fires when the timer ends.
- Completion is earned by elapsed time. Ending early is allowed but recorded
  honestly as what actually happened.
- **Realistic about iOS**: the app cannot block other apps. It does not pretend
  to. It keeps the screen awake, notices when you leave, and reports the truth.

## 5. Tools — 200+, categorised, with icons
Replaces 12 tools and monogram letters. Each tool gets a meaningful SF Symbol
and its brand colour rather than a letter. Search + category filter.

Real bundled logos are deliberately **not** fetched at runtime: that would tell
200 companies when a student opens the tab, break offline, and cost a request
per tile. The icon layer is built so bundled artwork can be dropped in later
without touching call sites.

## 6. Break it
Fake a session, tamper with the clock, forge entitlement, cross-user reads,
malformed input. Then remove anything unused.

## Not doing
